# ASCEND — Product UX Baseline Audit

**Date:** 2026-10-25  
**Target:** ASCEND Next.js Web Application (`F:\projects\ascend`, branch `feat/webapp`)  
**Scope:** Complete screen, state, and interaction inventory of the existing application.

---

## 1. Executive Summary

ASCEND is an exceptionally capable, feature-dense fitness web application built with Next.js 14, React 18, TypeScript, Tailwind CSS, Zustand persistence, and Supabase integration. It features a complete powerlifting and bodybuilding engine, an Indian-first food nutrition database of over 500 items with camera and barcode scanning, automated periodization block engines, offline synchronization, and localization in English and Hindi.

However, the rapid accumulation of features over 37 merged pull requests has resulted in:
1. **Severe Information Overload:** Dashboards display dozens of competing cards, chips, scores, and buttons simultaneously.
2. **Visual Inconsistency:** Hardcoded Tailwind classes, inconsistent card paddings, scattered font sizes (such as unofficial `3xs`), and divergent button treatments across modals.
3. **Fragile Interaction States in Workout Logging:** While lifting, athletes encounter overcrowded tables with steppers, RPE selectors, notes, and timers crammed together.
4. **Settings Clutter:** Settings mixes device appearance, athlete profile data, training periodization, push notification rules, telemetry, and account deletion into a single dense list.
5. **Lack of Dynamic Personalization:** While users can toggle Dark/Light mode, there is no way to choose alternate accent themes, nor can users toggle between a calm "Simple Mode" and a data-rich "Detailed Mode".

## 3. Baseline Build & Test Metrics

- **Next.js Production Build:** `✓ Compiled successfully`, all 13 routes generated (68.3 kB shared client bundle).
- **Automated Unit Tests:** 103 passed test suites (1,524 passing unit tests).
- **Core Design Tokens:** Located in `tailwind.config.js` and `src/app/globals.css`.
  - Default Vermilion: `#E44427` (RGB `228 68 39`)
  - Graphite: `#171916` (RGB `23 25 22`)
  - Chalk: `#F3F0E7` (RGB `243 240 231`)
  - Sage: `#858076` (RGB `133 128 118`)
- **Key Baseline Defect:** Personalization is restricted to Dark/Light theme toggle; no accent theme customization, no Simple vs Detailed information density toggle, and dashboard cards are statically laid out regardless of user fitness goals.
